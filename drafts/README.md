# پیش‌نویس‌ها

این پوشه برای سه نوع فایل است: پیش‌نویس عادل، نسخهٔ پیشنهادیِ بازبینی‌شدهٔ منتور، و یادداشت‌های بازبینی/آموزش.

متن انگلیسی، پیش‌نویس عادل، پیشنهاد منتور و ترجمهٔ تأییدشده باید همواره از یکدیگر قابل تشخیص باشند. نسخهٔ پیشنهادی بدون تأیید صریح عادل نهایی نیست.

## شناسهٔ کار

ساختار کار چنین است:

`فصل → واحد ترجمه → قطعهٔ تمرین → جمله`

برای نمونه، `C00-S02-P01` یعنی قطعهٔ تمرین نخست در واحد `C00-S02`. واحدهای `S` ممکن است بسیار بلندتر از ۳۰۰ واژه باشند؛ قطعهٔ `P` واحد معمول کار آموزشی است و معمولاً حدود ۲۵۰ تا ۳۵۰ واژه دارد.

## نام‌گذاری فایل‌های جدید

- پیش‌نویس عادل: `C00-S02-P01-draft-01.md`
- نسخهٔ بازبینی‌شدهٔ منتور: `C00-S02-P01-reviewed-01.md`
- یادداشت بازبینی: `C00-S02-P01-review-notes-01.md`

فایل‌های قدیمی فقط برای هماهنگی ظاهری تغییر نام داده نمی‌شوند.
