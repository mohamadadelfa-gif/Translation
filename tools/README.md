# Preparation tools

- `organize.ps1`: rebuilds working chapter divisions into `translation-preparation/`. By default it reads the tracked frozen snapshot `sources/revisiting-zero-hour-1945-structured.md`, strips only known project-generated unit/practice-chunk markers in memory, and then regenerates the working layer. An alternate input may be supplied with `-SourcePath` or `ZERO_HOUR_SOURCE_MD`. It can overwrite working files; test regeneration in a temporary checkout and review the diff before replacing manually reviewed preparation files.
- `test-dictionary.cjs`: validates the original Ariyanpour LD2 source. The source path must be supplied with `--source <path>` or `ARYANPOUR_LD2_PATH`. The tool refuses to run if the source SHA-256 differs from the known extraction source `d69ee28c3faa54648528e754aef85cb51f62f6330c0cadeed943ae2c5984d765`. The `--export-full` option regenerates the full glossary under `translation-references/aryanpour/`.

- `validate_translation_craft_corpus.py`: run with `python -B tools/validate_translation_craft_corpus.py`. Checks 59 aligned English/Persian sections, file existence and SHA-256 checksums. Pilot cases resolve by their `section` IDs through `paired-sections.csv`; malformed JSON, missing IDs, duplicate mappings and unresolved sections produce validation errors. Success does not certify OCR/transcription accuracy or translation quality. This validator reads files only.

The preparation tools resolve output paths from the project root regardless of the shell's current directory. `organize.ps1` is repository-reproducible from the tracked structured snapshot; the Ariyanpour LD2 remains an external binary dependency whose checksum is enforced. Neither tool should alter files in `sources/`.
