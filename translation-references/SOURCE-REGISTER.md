## Persian usage and orthography

- sources/Najafi — غلط ننویسیم.pdf: reference for usage questions. Read the relevant entry and assess its application to the passage.
- sources/فرهنگستان — دستور خط فارسی.pdf: reference for Persian orthography, including spacing and character conventions; verify edition-specific rules in the supplied text.

## Prose reference

- sources/گور به گور - ویلیام فاکنر.pdf: approved reference for studying translated Persian prose. Translator and edition have not yet been verified from its title pages. Select and discuss representative passages before deriving stylistic rules; do not automatically transfer a novel's narrative voice to academic essays.

## Use policy

Consult relevant sources according to the problem: meaning and context, technical terminology, Persian expression, usage, or orthography. Distinguish actual source lookups from independent proposals. Explain significant conflicts and leave final translation decisions with Adel. Never claim that a named reference supplies a wording without checking it.
