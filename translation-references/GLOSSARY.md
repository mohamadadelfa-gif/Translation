# Translation Project Glossary

This is the active terminology record for the English-to-Persian translation of *Revisiting Zero Hour 1945*.

The glossary records project decisions; it is not itself a dictionary or historical authority. Evidence must be identified separately from the mentor's contextual reasoning.

## Status rules

- **candidate** — proposed equivalent; not yet explicitly approved by Adel.
- **approved** — explicitly accepted by Adel for the stated sense/context.
- **reconsider** — an existing choice needs renewed review because the context or evidence has changed.
- **retired** — an older choice retained for traceability but no longer recommended.

Never treat a candidate as project-wide settled terminology. Approval applies to the stated sense and context, not automatically to every occurrence of the same word.
