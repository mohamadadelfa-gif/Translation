# Daryabandari — *As I Lay Dying* / «گور به گور» — Markdown Working Corpus

This directory is a translation-study corpus made from the scanned Persian edition translated by Najaf Daryabandari.

## Purpose

The corpus is intended to help the Translation Project study **how Daryabandari makes translated prose function as Persian**: syntax, rhythm, idiom, register, voice, compression/expansion, and de-calquing.

It is **not** a replacement for the scanned source.

## Working rule

For translation-craft analysis:

```text
find passage in structured Markdown
        ↓
check exact PDF page
        ↓
compare with Faulkner English
        ↓
identify Daryabandari's operation
        ↓
record reusable Persian translation principle
```

Do not derive a rule from OCR wording that has not been checked against the scan.
