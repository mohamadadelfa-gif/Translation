# Translation Operation Taxonomy — v0.1

This taxonomy is derived from the 12-case Daryabandari pilot.

## Semantic / conceptual
- situation-first reconstruction
- conceptual reconstruction
- ambiguity preservation
- image preservation
- semantic compensation

## Syntactic
- syntactic unpacking
- sentence segmentation
- clause reordering
- grammatical-category shift
- verbalization
- selective compression
- selective expansion

## Lexical / phraseological
- idiomatic substitution
- native collocation
- domain-language activation
- technical-term substitution
- conceptual paraphrase

## Voice / register
- controlled colloquialization
- marked-register recreation
- rhetorical elevation
- religious-register activation
- conceptual-register shift
- childlike fragmentation
- oral aggression

## Rhythm / discourse
- repetition preservation
- rhythmic compensation
- pause reconstruction
- fragment reconstruction
- causal-loop preservation

## Quality-control principle
Every transformation must be back-checked against the source for:
- lost meaning;
- added explanation;
- changed certainty;
- changed metaphor;
- changed argumentative relation;
- erased ambiguity;
- flattened register.
