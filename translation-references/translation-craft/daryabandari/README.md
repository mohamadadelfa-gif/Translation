# Daryabandari Translation-Craft Pilot

Files:

- `PERSIAN-TRANSLATION-CRAFT-PILOT.md` — full analytical report
- `parallel-cases.jsonl` — 12 machine-readable aligned case records
- `operation-taxonomy.md` — reusable operation labels

Pilot size: 12 aligned cases.

This package is intended to become a **craft/reference layer** in the Translation Project, separate from lexical authorities such as Ashouri and from project terminology decisions in `GLOSSARY.md`.
