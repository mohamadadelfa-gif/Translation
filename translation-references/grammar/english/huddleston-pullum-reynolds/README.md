# Huddleston–Pullum–Reynolds Grammar Reference

## Canonical source

`sources/grammar/english/Rodney Huddleston, Geoffrey K. Pullum, Brett Reynolds - A Student's Introduction to English Grammar (2022, Cambridge University Press) - libgen.li.pdf`

This directory is the derived retrieval and mentoring layer for Rodney Huddleston, Geoffrey K. Pullum, and Brett Reynolds, *A Student's Introduction to English Grammar*, 2nd ed. (Cambridge University Press, 2022).

The PDF in `sources/` remains the canonical source. Files in this directory are navigation and mentoring aids; they do not replace the book.

## Role in the Translation Mentor

Use this grammar to determine how an English sentence is structurally organized before translating it.

It is especially relevant for:

- identifying the matrix clause;
- distinguishing subjects, objects, predicative complements, and other complements;
- distinguishing complements from adjuncts;
- analysing noun-phrase structure;
- analysing prepositional phrases;
- analysing subordinate and relative clauses;
- analysing finite versus non-finite clauses;
- analysing coordination;
- analysing passive, extraposition, preposing, postposing, and other information-packaging constructions;
- analysing tense, aspect, auxiliaries, and modality.

The grammar is a source for **English grammatical analysis**. It is not:

- a bilingual dictionary;
- a Persian grammar;
- a translation-equivalence source;
- a historical source for German concepts;
- an authority on Persian wording.

## Mentoring principle

The mentor should use grammatical analysis to expose the relationships inside the English sentence before proposing a Persian reconstruction.

Preferred sequence:

```text
SOURCE SENTENCE
      ↓
IDENTIFY MATRIX CLAUSE
      ↓
IDENTIFY PHRASES / SUBORDINATE STRUCTURES
      ↓
IDENTIFY GRAMMATICAL FUNCTIONS
      ↓
IDENTIFY SCOPE AND DEPENDENCIES
      ↓
EXPLAIN HOW THESE RELATIONS AFFECT MEANING
      ↓
ONLY THEN COMPARE WITH PERSIAN STRUCTURE
```

The mentor should not turn grammatical terminology into an end in itself. The purpose is to help Adel understand what depends on what, which relations are meaning-bearing, and which aspects are merely English grammatical packaging.

## Evidence discipline

Do not say that Huddleston, Pullum, and Reynolds analyse a construction in a particular way unless the relevant chapter or section has actually been checked.

When practical:

- identify the chapter or section consulted;
- retain the printed page locator;
- distinguish the book's grammatical analysis from mentor inference about the specific Trommler sentence.

If the exact construction has not yet been checked in the source, label the analysis as mentor analysis rather than attributing it to the grammar.
