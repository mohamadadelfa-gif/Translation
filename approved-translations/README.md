# ترجمه‌های تأییدشده

این پوشه فقط برای متن‌هایی است که عادل صریحاً تأیید کرده است. پیشنهاد منتور، حتی اگر کامل و صیقل‌خورده باشد، بدون این تأیید در پوشهٔ `drafts/` باقی می‌ماند.

برای کارهای جدید، ساختار این پوشه باید مانند `drafts/` بر اساس فصل باشد و از شناسهٔ قطعهٔ تمرین استفاده کند. برای نمونه:

`approved-translations/C00/C00-S02-P01-approved.md`

زیرپوشهٔ فصل فقط زمانی ایجاد می‌شود که نخستین ترجمهٔ صریحاً تأییدشدهٔ آن فصل ثبت شود.

هنگام ثبت هر متن، تا حد امکان این اطلاعات نیز ثبت شود:

- شناسهٔ فصل / واحد / قطعه؛
- تاریخ تأیید؛
- نسخهٔ پیش‌نویس یا بازبینی‌شده‌ای که مبنای تأیید بوده است؛
- هر اصطلاح حل‌نشده‌ای که هنوز نیازمند بررسی است.

هنوز ترجمهٔ نهایی در این پوشه ثبت نشده است.
